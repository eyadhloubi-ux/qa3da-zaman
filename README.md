الدولاب بيدور لحاله، ولما الكل يكبس «جاهز» اللعبة بتبلّش لحالها (أو الريس بيكبس «بلّش هلأ»). وزر «إنهاء» فوق بيخلّي الريس يخلّص القعدة أو يبلّش قعدة جديدة بأي وقت.

اللي بيطلعوا نفس النتيجة بالضبط بياخدوا نفس المركز ونفس النقاط.

كل مرة اللعبة بتنلعب بشكل مختلف (رقم جديد، جملة جديدة، جورة بمكان تاني…)، بس كل اللاعبين بنفس الجولة بياخدوا نفس التحدي.

## الرفع على GitHub و Render (خطوة بخطوة)

1. **GitHub:** اعمل مستودع جديد (مثلاً `qa3da-zaman`)، وارفع كل الملفات اللي بهالمجلد ما عدا `node_modules` (مستبعدة تلقائياً).
2. **Render:** ادخل على [render.com](https://render.com) ← **New** ← **Blueprint** ← اختار المستودع.
3. Render بيقرأ ملف `render.yaml` لحاله وبيجهّز كل شي. اكبس **Apply**.
4. بعد دقيقتين بيطلعلك رابط متل `https://qa3da-zaman.onrender.com`. هاد رابط اللعبة اللي بتحطه بالـBio.

### مفتاح الإدارة
- Render بيولّد قيمة `ADMIN_KEY` لحاله. بتلاقيها بـ **Environment** جوّا الخدمة.
- **صفحة الإدارة:** `https://رابطك/admin?key=المفتاح` (إحصائيات + القعدات الشغالة + إغلاق قعدة).
- **الإحصائيات بس:** `https://رابطك/stats?key=المفتاح`

### حتى ما تضيع الإحصائيات (اختياري)
الخطة المجانية بـRender بتمسح الملفات كل ما الخدمة تعيد التشغيل. إذا بدك الإحصائيات تضل محفوظة:
1. بـRender: **New** ← **Postgres** (في خطة مجانية).
2. انسخ **Internal Database URL**.
3. بخدمة اللعبة ← **Environment** ← حط `DATABASE_URL` = الرابط.

> ملاحظة: بالخطة المجانية، أول فتحة بعد فترة هدوء بتاخد حوالي 30 ثانية لتصحى الخدمة.

## التشغيل على جهازك

```bash
npm install
npm start
```
وافتح `http://localhost:3000`. لتجرّب بأكتر من لاعب، افتح الرابط بكذا متصفح أو موبايل على نفس الشبكة.

## شو في جوّا

- `server.js` — السيرفر (Express + WebSocket): القعدات، الجولات، النقاط، الإحصائيات، صفحة الإدارة.
- `public/index.html` — الصفحة.
- `public/app.js` — الشاشات: الدخول، الانتظار، دولاب القنوات، النتيجة، صورة الستوري.
- `public/games.js` — الألعاب التسعة.
- `public/style.css` — التصميم.
- `public/fonts/` — الخطوط (مستضافة مع اللعبة، فبتشتغل حتى بلا نت بعد التنزيل).
- `render.yaml` و `Dockerfile` — للنشر.

## ملاحظات تقنية

- «ظبّط الأنتين» بيستخدم حساس الميلان. عالآيفون بيطلب إذن لما اللاعب يكبس «جاهز». إذا ما في حساس، بيشتغل بالسحب.
- الرابط لازم يكون **HTTPS** (Render بيعطيه تلقائياً) حتى يشتغل الحساس والكاميرا والتنزيل كتطبيق.
- إذا انقطع النت أو انعمل تحديث للصفحة، اللاعب بيرجع لنفس مكانه.
- إذا طلع الريس، بعد 45 ثانية أي حدا بالقعدة بيقدر يصير الريس.
